# Calculadora em Pascal

Calculadora simples desenvolvida em **Object Pascal** utilizando o **Lazarus**, como parte do meu aprendizado da linguagem.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Limpar a tela
- Tratamento de divisão por zero

## O que aprendi

Durante o desenvolvimento pratiquei conceitos básicos de Pascal, como:

- Declaração de variáveis e tipos (`Double`, `Char`);
- Uso de `:=` para atribuição;
- Estruturas `if`, `then`, `else` e `case`;
- Criação e uso de eventos dos botões;
- Uso de componentes como `TForm`, `TEdit` e `TButton`;
- Conversão entre texto e números com `StrToFloat` e `FloatToStr`.

A lógica da calculadora consiste em armazenar o primeiro número e a operação escolhida, receber o segundo número e, ao clicar em `=`, realizar a operação correspondente e mostrar o resultado na tela.

## Tecnologias

- Object Pascal
- Lazarus IDE
- Free Pascal
